# Fashionista - Modern Apparel & Fashion E-Commerce Store

A chic, modern fashion storefront web application built with **HTML5**, **CSS3**, and **Bootstrap** for clothing brands and apparel retailers.

## ✨ Key Features
- **Trendy Apparel Catalog**: Browse seasonal fashion lines, streetwear, formal wear, and designer accessories (`shop.html`).
- **Interactive Lookbook Carousel**: Dynamic hero sliders highlighting trending collections, discounts, and new arrivals.
- **Product Card Interactions**: Quick view previews, size/color selectors, and hover state animations.
- **Contact & Store Locator**: Dedicated contact portal with customer inquiry forms and store branch details (`contact.html`).
- **Responsive Layout**: Pixel-perfect presentation across mobile phones, tablets, and wide monitors.

## 📁 Project Structure
- `index.html` - Brand homepage with trending hero collections
- `shop.html` - Product catalog and filtering interface
- `contact.html` - Customer support and inquiry page
- `css/` - Custom styling and responsive overrides
- `js/` - Interactive slider and product modal scripts
- `images/` - High-resolution fashion lookbook imagery
